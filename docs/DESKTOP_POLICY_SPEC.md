# Windows 桌面管控功能规格（锁屏及壁纸管理）

> 来源：用户需求原文（2026-09-16），作为 desktop-policy 专项的权威规格。
> C/S 架构；服务端复用现有控制台（Python 3 标准库 + SQLite，遵循 ADR-002，禁第三方依赖）。

## 一、背景
在现有管理控制台项目基础上新增对 Windows 客户端终端的桌面环境统一管控能力。

## 二、总体架构
1. **服务端（复用现有控制台）**：
   - 新增「终端桌面管控」模块：壁纸资源库管理、策略配置、终端分组、下发记录
   - 壁纸资源库：按分类（科室/院区/节日/宣传/默认）管理图片，记录每张图的分辨率、宽高比、文件大小、适用终端类型
   - 策略模型：桌面壁纸策略 / 锁屏壁纸策略 / 电源计划策略 / 超时锁屏策略，支持按终端组下发，支持定时轮换（每天/每周/指定日期）
2. **客户端（新增，Windows 常驻程序，随系统启动）**：
   - 定时/事件驱动向服务端拉取策略（HTTPS 轮询即可）
   - 本地执行壁纸设置、锁屏壁纸设置、电源计划切换、超时锁屏参数应用
   - 本地 SQLite 缓存策略与壁纸文件，服务端不可达时保持上次配置（离线兜底）

## 三、功能需求明细
1. **桌面壁纸管理**：按策略设置/定时轮换桌面壁纸；多显示器支持（每屏独立壁纸）；缩放模式可选（填充/适应/拉伸/平铺/居中）
2. **锁屏壁纸管理**：注册表 PersonalizationCSP（HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\PersonalizationCSP）方式设置（Win10/11）；与桌面壁纸策略相互独立
3. **电源计划设置**：内置计划切换（平衡/高性能/节能）；自定义计划（显示器关闭/睡眠/硬盘关闭超时、电源键行为，AC/DC 双通道）；powercfg 或 PowerSetActiveScheme 实现
4. **超时锁屏设置**：屏保等待时间 + 恢复时显示登录屏（Secure）；显示器关闭超时触发锁屏（video idle）；可选「空闲 X 分钟后主动锁屏」（GetLastInputInfo）

## 四、壁纸分辨率自适应（核心要求）
1. 客户端启动及每次策略拉取时上报本机显示器信息：数量、每屏分辨率、DPI 缩放、主屏标识
2. 服务端匹配推荐：精确匹配优先 → 宽高比一致且分辨率不低于目标 → 完全无匹配下发默认壁纸并记录告警
3. 非精确匹配图片先本地缩放裁剪再应用（不变形、无黑边）
4. 分辨率变化（外接显示器/投影/RDP）自动重新匹配应用（WM_DISPLAYCHANGE）

## 五、技术约束
1. 全部 Python 3 标准库：GUI/托盘 tkinter（客户端可无界面，以 Windows 服务或启动项常驻）、HTTP 用 http.server、Win32 统一 ctypes
2. 桌面壁纸：SystemParametersInfo(SPI_SETDESKWALLPAPER)；多显示器经临时拼接图（IPicture/TranscodedWallpaper 机制）
3. 锁屏壁纸：写注册表 + 复制文件到对应路径后触发刷新
4. 电源/超时：powercfg /SETACVALUEINDEX、/SETDCVALUEINDEX、/SETACTIVE；执行前备份当前方案 GUID
5. 执行结果写本地日志（日期分文件），失败重试 3 次（指数退避），最终失败上报服务端记录
6. 界面与日志文案全部简体中文（代码标识符、命令、注册表路径保留英文）

## 六、非功能要求
1. 客户端常驻内存 < 50MB，空闲 CPU < 1%
2. 权限：锁屏壁纸（HKLM）与电源计划需管理员权限——客户端安装时申请并说明；桌面壁纸无需提权
3. 兼容 Windows 10 1809+ 与 Windows 11，两系统实测
4. RDP 会话下策略不误应用本地壁纸（检测会话状态）

## 七、交付物
1. 服务端模块代码 + 数据库迁移脚本（SQLite 新表）
2. 客户端程序 + 开机自启动安装脚本
3. 接口文档（客户端-服务端通信协议：JSON over HTTP）
4. 测试报告：多分辨率（1920x1080 / 2560x1440 / 3840x2160 / 双屏异分辨率）适配实测截图、电源计划切换前后 powercfg /q 输出对比

## 八、验收标准
1. 指定终端组下发壁纸策略，2 分钟内（一个轮询周期）客户端生效
2. 1080p 终端下发 4K 壁纸，实际显示无变形、无黑边
3. 锁屏壁纸在 Windows 10/11 锁屏界面实测生效
4. 电源计划与超时锁屏策略应用后，powercfg /q 与注册表值与配置一致
5. 断开服务端连接，客户端保持现有配置不回退

## 九、用户提醒（实施重点）
1. **多显示器独立壁纸**是技术难度最高点（Windows 原生 API 不支持每屏单独壁纸，业界通行做法是拼接图）——重点验收
2. **锁屏壁纸 HKLM 需管理员权限**：终端用户普通权限运行时，客户端须以服务方式部署（LocalSystem）——实施阶段提前定
