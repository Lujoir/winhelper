# Disk Cleaner — C盘磁盘清理与应用数据迁移（独立项目）

> 观枢终端平台（EyeTerm）· 磁盘清理子系统

由 winhelper 主应用的磁盘清理功能**迁移**而来的独立项目，由专属开发 agent（disk-cleaner-dev）负责演进。

## 运行

```powershell
pip install flask
python app.py        # http://127.0.0.1:5010
```

## 功能

| 模块 | 说明 |
|---|---|
| C盘容量概览 | 容量进度条 + 统计 |
| 垃圾文件分析 | 14 类安全/谨慎分级 · 默认勾选推荐项 · 实时清理进度 |
| 安装包清理 | 下载/桌面/浏览器下载目录/全盘/自定义目录 · 置信分级 · 全选总控 |
| C盘应用数据迁移 | 微信/QQ/钉钉/腾讯会议/桌面/下载 盘点 · 迁移数据盘 · 谨慎删除 |
| 容量定位分析 | 智能推荐TOP10 · 目录树下钻 · 海量小文件识别 · 大文件TOP25 |
| 容量仪表盘 | squarified treemap 可视化 · 渐变配色 · 点击下钻 |

## 安全模型（必读）

见 `docs/DECISIONS.md`（ADR-001~008）。核心：**数据安全优先**——
清理走服务端白名单；大文件只定位不删除；微信/QQ 数据库绝不触碰；迁移=移动不删除。

## 开发约定

- 修改后必须：`python -m py_compile`（PY）+ esprima 校验（JS）+ 冒烟测试 + git commit
- 禁止硬编码盘符；禁止绕过白名单；破坏性操作必须有确认与进度
