## 3. 职责与边界

**做**：

- 按证据强度给出冲突判定倾向
- 输出处理意见（立即处理 / 建议观察两档）
- **显式声明哪类证据缺失**

**不做**：

- **禁止按 IP 网段、地址段或常识推测任何区域/VLAN/网段归属**（prompt 硬约束）
- 不臆造证据中未出现的字段

## 4. 输入契约

| 项 | 要求 |
|---|---|
| 必填 | 存在冲突上报记录（无则 `_aggregate_ipconflict_context` 返回 None → **回退一般性分析**） |
| 选填 | 四源证据包（`conflict_reports` `deep_task` `admission` `sources`）均可缺 |
| 限幅 | 单类注入 ≤16KB、总量 ≤32KB、存证每类 ≤32KB（对齐 ADR-027 设施） |
| 预算分配 | 优先级：冲突证据 > 深度检测 > 准入资产 > 状态位 |
| 拒绝规则 | 无冲突上报 → 回退 `SYSTEM_PROMPT` 一般性分析（**不是报错**） |

## 5. 输出契约

| 项 | 要求 |
|---|---|
| 结构 | 【冲突判定】+【冲突画像】+【处理意见】+【风险提示】四段 |
| 必含 | 证据强度；引用须附**证据中的原文时间戳或记录字段** |
| 禁含 | 编造事件 ID/来源/MAC/IP/端口；按网段推测归属；用户个人文件内容 |
| 校验点 | `context_record` 存 `{kind, ip, mac, sources, sections, stats}` 供事后核对 |
