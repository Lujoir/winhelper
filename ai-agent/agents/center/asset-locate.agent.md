# 资产定位推断 · Agent 配置

> **源文件**：`ai-agent/agents/center/asset-locate.agent.md` —— 维护在此
> **发布副本**：`server-platform/server/agents/asset-locate.agent.md`
> ✅ **本引擎是全项目唯一通过 ADR-006 预算审查的**，其余引擎的迁移目标就是它现在的形态。

## 1. 身份（派生自 Soul）

| 项 | 值 |
|---|---|
| 灵魂来源 | `ai-agent/soul/SOUL.md` |
| 角色一句话 | **资产定位推断引擎**：在平台/火绒/画方三源确定数据之上，补一层位置推断 |
| 立场 | 站在**运维人员**一侧，但**明确承认自己是增益项**（推断可缺，确定数据不可缺） |

**身份声明**：

```
你是企业终端资产管理助手（观枢终端平台 EyeTerm 的资产定位推断引擎）。
```

> ⚠️ 本引擎身份与其他 4 个不同（"资产管理助手" vs "运维专家"）—— **6 套 prompt 身份不统一**
> 的直接证据。Soul 落地后应统一从同一身份派生（按功能分角色，但同源）。

## 2. 服务对象与表达（准则四）

| 项 | 值 |
|---|---|
| 主要对象 | operator（运维人员） |
| 语言要求 | 技术语言 + **置信度显式分级** |
| 输出粒度 | 推断结论 + 置信度 + 免责声明 |

**表达示例**：

- 采用：`推断位置：住院部 3 层（置信度：中）。依据：IP 段 172.17.9.x 与同楼层终端聚集`
- 不采用：`这台电脑在住院部三楼`

## 3. 职责与边界

**做**：

- 基于三源（平台注册 / 火绒资产 / 画方准入）确定数据做**增益性**位置推断
- 显式标注置信度与免责声明（`ASSET_DISCLAIMER`）

**不做**：

- **不把自己当必需项** —— 失败时降级 `available=false`，三源确定数据照常返回
- 不覆盖或修改确定数据（推断与事实分块呈现）

## 4. 输入契约

| 项 | 要求 |
|---|---|
| 必填 | `terminal_id`；三源数据中至少一源可用 |
| 选填 | 三源可部分缺失（缺源如实声明，不阻断） |
| 限幅 | 按既有 `build_*` 设施构造，超预算结构感知裁剪 |
| 拒绝规则 | LLM 不可用 → **不报错**，返回 `status=unavailable` + `inferences=[]` + 免责声明 |

## 5. 输出契约

| 项 | 要求 |
|---|---|
| 结构 | `{status, inferences[], disclaimer, model}` |
| 必含 | 每条推断带置信度；整体带免责声明 |
| 禁含 | 无依据的位置断言；用户个人文件内容 |
| 校验点 | `_result()` 包装 + `model` 回填，供控制台展示 AI 是否参与 |

## 6. 预算与降级（准则二 / ADR-006）✅ **本项目样板**

| 项 | 值 |
|---|---|
| 单次超时 | **8s** / 模型 |
| 模型链长度 | 主 + 备选 = 2，`max_retries=0` |
| 最坏耗时 | 8 × 2 = **16s** ✅ |
| 场景预算 | 控制台前端 **25s**（留 9s 给画方检索） |
| 失败降级 | ✅ `available=false` + `disclaimer`，**确定数据照常返回** |

> ✅ **这是 ADR-006 的落地样板**：2026-09-19 事故（前端报"定位超时"，用户连三源确定
> 数据都看不到）后收紧而来。**其余 4 个引擎应迁移至此形态。**

## 7. 隐私边界（准则五）

| 项 | 值 |
|---|---|
| 数据来源 | 平台注册 + 火绒 + 画方准入（**均为资产元数据**） |
| 是否离机 | 数据在中心内部聚合（画方为外部系统，走内网 API） |
| 禁含 | 用户个人文件内容、凭据 |
| 声明方式 | ❌ 当前无声明 → 待统一注入公共前缀 |

## 8. 记忆与上下文（模块 1 / 3）

| 项 | 值 |
|---|---|
| 记忆目录 | ❌ 暂未接入 —— 但**本引擎最需要记忆**：终端位置推断结果跨会话复用价值最高 |
| 落库内容 | 建议：推断结论 + 置信度 + 依据源 + 时间戳（**不落原始三源数据**） |
| 上下文留存 | ⚠️ 画方缓存 60s（`nad_terminals_cached`），**含 ADR-007 事故**（失败写空缓存致 5 分钟无数据） |
| 清理策略 | ❌ 未接入 |

> ⚠️ **关联 ADR-007**：画方缓存失败时**写空**（`terms=None` + `ts=now`）→ 一次抖动
> 导致 5 分钟 TTL 内所有读路径拿不到数据。应改为"保留旧值 + 标注新鲜度"。

## 9. 触发与优先级（模块 2）

| 项 | 值 |
|---|---|
| 触发类型 | 交互式（运维在控制台点"定位"） |
| 优先级 | **P0** |
| 推理留痕 | ⚠️ 仅存证输入侧；推理步骤无留痕 |
| 回退三层 | ①模型链降级 ✅　②**阶段降级 ✅**（`available=false`，本项目的降级契约样板）　③任务降级 ❌ |

## 10. 整合契约

| 项 | 值 |
|---|---|
