# soul/archive/ — Soul 历史版本

Soul 文件**只读、版本化**：任何变更都必须保留旧版，便于回答"人格是什么时候、
因为什么变的"。

## 变更流程

1. 人工（**不得由自动化流程**）编辑 `../SOUL.md`
2. **变更前**把当前版本复制进来：`SOUL-<YYYYMMDD_HHMMSS>.md`
3. 在 `../../docs/DECISIONS.md` 追加一条 ADR，写明：
   - 改了什么（哪条准则/目标）
   - 为什么改（触发情形）
   - 影响哪些模块的行为

## 为什么这么严格

Soul 定义的是**核心身份、行为准则与长期目标**。它一旦被自动流程改写，
所有模块的行为取向都会漂移，而且**事后无法追责**——不知道是哪次任务、
哪个环节把它改成了现在这样。

所以：Soul 的变更权只属于人，且必须留痕。
